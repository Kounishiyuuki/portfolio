# Portfolio

Japanese-first IT job-hunting portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Scope

- Featured Projects: WinCook, Share Fit, AIVY
- All Works: Portfolio, PulseCue
- Project images use real README or repository assets only.
- Coursework or weak learning repositories are intentionally not shown.

## Scripts

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run build
```

## Verification

Before committing release-ready portfolio changes, run:

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

Also inspect these routes in a browser at mobile and desktop widths:

- `/`
- `/projects`
- `/projects/wincook`
- `/projects/share-fit`
- `/projects/aivy`
- `/about`
- `/skills`
- `/contact`

## Notes

- Generated files such as `.next`, `node_modules`, and `tsconfig.tsbuildinfo` should not be committed.
- `.codex` workflow and skill files are kept as project-local collaboration notes.
